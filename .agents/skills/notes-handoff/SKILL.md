---
name: notes-handoff
description: Hand off or resume unfinished Notes work using the branch, task record and verification evidence.
---

- Update the shared ticket or branch-local handover using [the template](../../../docs/HANDOVER.md). Include the owner, exact base and head, scope, decisions, completed work, outstanding edits, commands and results, blockers and next action. Push the checkpoint branch only when authorized.
- On resumption, read the task record and `AGENTS.md`. Confirm the assignment, worktree, SHA, status and diff against the recorded base. Locate any uncommitted work and preserve it. Ask the current owner about conflicting edits before taking over.
- Re-run the most relevant check on the recorded revision. For review-ready work, have a separate reviewer verify the committed SHA and record their own result.
