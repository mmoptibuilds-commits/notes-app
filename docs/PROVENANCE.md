# Provenance

What Notes is made of and where each part comes from. Licence texts and the
dependency inventory are in [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).
This is a factual record, not legal advice.

## Relationship to the upstream "Notebook" app

Notes replaces the note-taking part of an earlier app ("Everything App",
Android package `com.saadhjawwadh.notebook`) for its owner. That app has no
licence file, so nothing from it is used in Notes:

- **Code.** Notes is an independent implementation written in this repository
  (see Git history from `49e82eb`, 2026-11-17). A mechanical comparison on
  2026-11-21 found no shared Dart source: zero shared normalized six-line runs
  across 91 Notes and 260 upstream files; the only shared long string literals
  were package import paths and one generic sentence. Byte-identical files were
  limited to standard `flutter create` scaffold files and the Inter font (an
  OFL font both apps bundle, see below). The comparison is a heuristic.
- **Data format.** The importer (`lib/importer/legacy_backup.dart`) reads the
  upstream app's backup JSON so the owner can bring their notes across. This is
  format interoperability; no upstream code is involved.
- **Name and identity.** Notes uses its own name, app id
  (`com.mmoptibuilds.notes`), icon and design.
- **Publication basis.** The owner publishes Notes as their own independent
  work; no permission from the upstream author is claimed or relied on
  (owner's decision, 2026-11-21).

A copy of the upstream app may exist locally in the git-ignored `.reference/`
directory for behavioural comparison. It must never be copied into Notes.

## Assets

| Asset | Origin |
|---|---|
| App icon, launcher icons, splash glyph (`assets/icon/`, `android/app/src/main/res/mipmap-*`) | Original. Drawn by code in this repository (`lib/ui/brand_mark.dart`, generated by `tool/generate_icons.dart`); AI-assisted, created for this app. |
| Inter (`assets/fonts/Inter*.ttf`) | The Inter Project, SIL OFL 1.1, file metadata `Version 4.001;git-66647c0bb`. Byte identity with a specific official release file has not been established; the licence permits redistribution with its notice either way. |
| Source Serif 4, JetBrains Mono, Atkinson Hyperlegible | SIL OFL 1.1 (see THIRD_PARTY_LICENSES.md). |
| Screenshots in `docs/screenshots/` | Rendered from synthetic data. |

The OFL texts ship in both packages (APK assets and Linux archive root), and the
in-app page Settings → Open-source licences lists every package and font
licence.
